# DeutschMate

Your personal AI companion for mastering German(later other languages to be included).

## Features

- CEFR-based German conversations
- Grammar correction
- Vocabulary suggestions
- Translation
- Pronunciation analysis
- Voice chat
- Interview preparation mode

## Tech Stack

### Frontend
- React Native
- TypeScript
- Expo

### Backend
- FastAPI
- PostgreSQL
- Redis

### AI
- Ollama
- Qwen3
- Faster Whisper
